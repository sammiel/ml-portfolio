Applied machine learning for customer analytics

Three small, interactive projects based on problems I have worked on in banking and enterprise education: spotting customers likely to leave, scoring account health, and forecasting demand. Each model is trained in Python and runs in your browser.

All data is synthetic, generated to resemble real patterns. No employer or customer data is used.
Classification

Churn risk scorer

Predicts which retail-bank customers are likely to leave next quarter and explains why. Includes a benchmark against gradient boosting and a calibration check.

Open project → Scoring

Customer health scoring

Turns account usage into a 0 to 100 health score fitted to renewal outcomes, with a portfolio view and what-if analysis for each account.

Enrolment forecasting

Forecasts weekly enrolments with trend, seasonality and a 90% range, built in NumPy and backtested against naive baselines.

Stack

Python, NumPy and scikit-learn for data generation, training and evaluation. Models are exported to JSON and scored in plain JavaScript; charts use Chart.js. Hosted as a static site on Netlify. Source code on GitHub.
